# Keyboard map reference

These images are regenerated automatically by the `Draw keymap visualizations`
workflow on every push — SVG for crisp scaling in Obsidian, PNG for quick
viewing elsewhere. To look one up fast, use the `keymap-lookup` script at the
repo root, or the Obsidian note below.

## Obsidian note (copy this into your vault)

Put this in a note named e.g. `Keyboard layout`:

````markdown
# Keyboard layout

> Generated by the `Draw keymap visualizations` GitHub Action.
> To update: `git pull` (or push a keymap change) — images refresh automatically.

## Skeletyl

![[bastardkb_skeletyl_vendor.svg]]

## Skeletyl (shur3d)

![[bastardkb_skeletyl_shur3d.svg]]
````

Replace the filenames with the boards you actually use. Each SVG contains every
layer stacked vertically with a colored band per layer — the outline panel
(`Ctrl+O` → the note, then the heading outline) jumps straight to a layer.

### Keep the images auto-updated in your vault

If your vault can see the repo (recommended), symlink the generated folder so
`git pull` refreshes the pictures with zero copying:

```sh
ln -s /path/to/qmk_userspace/keymap_images ~/YourVault/attachments/keymaps
```

Obsidian follows folder symlinks. If the vault lives *inside* the repo, skip the
symlink and embed `keymap_images/...` relative paths directly.

### If your vault can't see the repo

`git clone` the repo anywhere, then copy `keymap_images/*` into your vault once
per update (or keep the symlink pointing at the clone).

## Quick lookup outside Obsidian

```sh
./keymap-lookup              # interactive picker (fzf)
./keymap-lookup skeletyl     # open the Skeletyl map
./keymap-lookup skeletyl --peek   # show inside kitty
./keymap-lookup --list       # what's available
```

Bind a global hotkey to `keymap-lookup skeletyl` (Settings → Keyboard →
Custom Shortcuts in GNOME/KDE) for instant access while typing.
